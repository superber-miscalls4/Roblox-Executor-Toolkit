## FAQ

### Is XCutors safe to use?

XCutors itself does not modify Roblox game files directly. It provides an interface to load and run Lua scripts. Always use trusted scripts and scan files with your anticomponent.

### Do I need all the executors installed?

No. The universal loader (xcutorsLoader) allows you to select and use any of the included executors (Volt, Synapse Z, Potassium, Wave) on demand. You can install only the ones you prefer.

### Will this get my Roblox account banned?

Using any third-party script executor violates Roblox's Terms of Service and carries a risk of account suspension. Use at your own discretion.

### How do I update the executors?

The application has a built-in auto-updater. You can also manually check for updates from the 'Settings > Updates' menu.

### My anticomponent flags the download. Is it a false positive?

Some security software may flag executor tools due to their nature. If you downloaded from our official GitHub releases, it's likely a false positive. You can scan the file yourself and add an exception.

### Can I add my own scripts?

Yes. Place your Lua (.lua) files in the 'Scripts' folder in the application directory. They will appear in the script library on the next launch.

### Which executor is recommended?

All included executors are functional. Synapse Z is popular for its stability, while others may have different performance or feature sets. Try them to see which works best for your needs.

### Does this work on macOS or Linux?

No. XCutors is designed specifically for Windows desktop environments.
